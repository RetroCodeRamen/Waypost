iPhone / iPad
  1. Open this page in Safari and tap Download Station certificate, then Allow.
  2. Settings → Profile Downloaded → Install.
  3. Settings → General → About → Certificate Trust Settings → turn on “Waypost Station Local CA”.
Android
  1. Download the certificate.
  2. Settings → Security → More security settings → Encryption & credentials → Install a certificate → CA certificate.
  3. Pick waypost-ca.crt from Downloads. Menu names vary by maker; search Settings for “CA certificate”.
macOS
  1. Download and double-click the certificate; add it to the System keychain.
  2. In Keychain Access, open “Waypost Station Local CA” → Trust → Always Trust.
Windows
  1. Download and open the certificate → Install Certificate → Local Machine.
  2. Choose “Place all certificates in the following store” → Trusted Root Certification Authorities.
Linux / Firefox
  1. Debian/Ubuntu: sudo cp waypost-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
  2. Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.
